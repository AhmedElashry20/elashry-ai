# elashry-ai

مساعد برمجة شخصي بيشتغل في VS Code، وجنبه نموذج لغوي متدرَّب من الصفر.

المشروع جزئين منفصلين:

| | إيه هو | الحالة |
|---|---|---|
| **`extension/`** | إكستنشن VS Code: شات + إيجنت بيعدّل ملفات وينفّذ أوامر | شغال |
| **`model/`** | ترانسفورمر decoder-only متدرَّب من الصفر (بدون أوزان جاهزة) | بيتدرّب |

مخ الإكستنشن دلوقتي **[OmniRoute](https://github.com/AhmedElashry20/OmniRoute)** — بوابة بتوصل مئات المزوّدين من نقطة واحدة. النموذج المحلي لسه بيتدرّب جنبه وبيخدم الـ embeddings.

---

## الإكستنشن

### المزايا

- **شات بأدوات** — بيقرا ويكتب ويعدّل ملفات، بيشغّل أوامر، بيدوّر في الكود
- **مهارات** (`$اسم`) — ملفات إرشادات بتتحقن في البرومبت
- **أهداف** — برومبت + معايير قبول، والإيجنت بيلف لحد ما تتحقق
- **أذونات** — `strict` / `approve` / `full`، والأوامر الخطرة مرفوضة بقواعد ثابتة
- **أتمتة** — برومبت على ميعاد (يومي / أيام الشغل / أسبوعي)
- **محادثات محفوظة** — ترجع لأي محادثة قديمة والسياق بيرجع معاها

### التشغيل

```bash
# 1) البوابة (مخ الشات)
npm i -g omniroute
OMNIROUTE_SERVER_HOST=127.0.0.1 omniroute serve     # 127.0.0.1:20130

# 2) الإكستنشن
cd extension && npm install && npm run compile       # بعدها F5 في VS Code
```

إعدادات VS Code:

```json
{
  "elashryAi.model.host": "http://127.0.0.1:20130",
  "elashryAi.model.chatModel": "auto",
  "elashryAi.agent.permissionMode": "approve"
}
```

> `OMNIROUTE_SERVER_HOST=127.0.0.1` مش اختياري: السيرفر افتراضيًا بيسمع على
> `0.0.0.0` من غير مفتاح، يعني أي جهاز على الشبكة يقدر يستهلك مزوّديك.

### المهارات والأهداف

مهارة = مجلد فيه `SKILL.md`، في `.elashry/skills/` (للمشروع) أو `~/.elashry/skills/` (لكل المشاريع):

```markdown
---
name: explain-code
description: يشرح كود بالعربي
---
# إرشادات
...
```

هدف = JSON في `.elashry/goals/`:

```json
{
  "prompt": "صلّح أخطاء TypeScript",
  "maxRounds": 5,
  "criteria": [
    { "type": "command", "run": "npx tsc --noEmit", "expectExit": 0 }
  ]
}
```

**المعايير حتمية عن قصد** — أوامر لازم ترجع 0، وملفات لازم تكون موجودة. مش حكم
موديل. فالإيجنت مايقدرش يقول "خلصت" وهو ما خلّصش.

## النموذج

ترانسفورمر decoder-only على طريقة nanoGPT. **من غير أي أوزان جاهزة** — التوكنيزر
والأوزان كلها متدرَّبة من الصفر.

| | |
|---|---|
| الباراميترات | 17.9M (12 طبقة · 8 رؤوس · بُعد 256 · سياق 256) |
| المفردات | 16,384 (BPE متدرَّب من الصفر) |
| الكوربَس | 2.61 مليار توكن — كود بـ 88 لغة + أمن سيبراني + عربي |

### الخطوات

```bash
python -m venv .venv && .venv/bin/pip install -r model/requirements.txt

.venv/bin/python model/scripts/train_tokenizer.py     # توكنيزر
.venv/bin/python model/scripts/prepare_data.py        # الكوربَس الأساسي
.venv/bin/python model/scripts/add_all_langs.py       # +88 لغة برمجة
.venv/bin/python model/scripts/train.py --preset nano_cpu --resume
.venv/bin/python model/scripts/generate.py --preset nano_cpu --agent --prompt "def factorial(n):"
```

### أدوات مساعدة

| السكربت | بيعمل إيه |
|---|---|
| `bench.py` | يقيس إنتاجية التدريب لتوليفة threads/batch |
| `grow_model.py` | يزوّد الطبقات **من غير ما يضيّع التدريب** (إسقاطات مصفّرة = ممر) |
| `trainwatch.sh` | يرجّع التدريب لو اتعلّق بعد نوم الجهاز |
| `ollama_adapter.py` | يخدم النموذج المحلي على 11435 (للـ embeddings) |

### ملاحظات على التدريب (مقيسة مش متخمّنة)

- **خيوط أقل أحسن** على معالج بيتخنق حراريًا: 4 خيوط أسرع من 8
- **batch 24** أحسن من 12 و48 — الأكبر بيفيض كاش L3
- **الحفظ لازم يبقى دوري مش عند أحسن val بس**، وإلا إعادة التشغيل بترجّعك لورا
- `grow_model.py` بيتحقق إن الـ loss ماتغيرش قبل ما يكتب أي حاجة

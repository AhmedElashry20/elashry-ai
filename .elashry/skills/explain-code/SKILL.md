# إرشادات

- اقرا الملف كامل الأول بـ `read_file` قبل ما تشرح.
- ابدأ بجملة واحدة: الكود ده بيعمل إيه.
- بعدها الخطوات بالترتيب، كل خطوة سطر.
- لو فيه باج أو حاجة خطر، قولها في الآخر تحت عنوان "انتبه".
- ماتكتبش الكود تاني — اشرحه بس.

elashry-ai

مساعد برمجة شخصي بيشتغل جوه VS Code — وجنبه نموذج لغوي متدرَّب من الصفر، من غير أي أوزان جاهزة.

الكود على GitHub طريقة التشغيل

الإكستنشن

إيجنت بيشتغل على الكود مش بيتكلم عنه بس.

أدوات حقيقية

بيقرا ويكتب ويعدّل ملفات، بيشغّل أوامر، وبيدوّر في الكود. كل خطوة بتعدية عليك قبل ما تتنفّذ.

مهارات

اكتب $اسم-المهارة في الشات، والإرشادات بتتحقن في البرومبت. ملفات عادية في مشروعك.

أهداف

مش برومبت وخلاص — برومبت + معايير قبول. الإيجنت بيفضل يلف لحد ما تتحقق.

أذونات

ثلاث أوضاع، والأوامر المدمّرة (rm -rf، sudo، curl | sh) مرفوضة بقواعد ثابتة.

أتمتة

برومبت بيتنفّذ على ميعاد — يومي، أيام الشغل، أو أسبوعي.

محادثات محفوظة

ارجع لأي محادثة قديمة، والسياق بيرجع مع الإيجنت نفسه فيكمّل من حيث وقف.

الأهداف — الفكرة الأساسية

المعايير حتمية عن قصد: أوامر لازم ترجع صفر، وملفات لازم تكون موجودة. مش حكم موديل.

// .elashry/goals/fix-types.json
{
  "prompt": "صلّح أخطاء TypeScript",
  "maxRounds": 5,
  "criteria": [
    { "type": "command", "run": "npx tsc --noEmit", "expectExit": 0 }
  ]
}
ليه حتمية؟ لأن الموديل اللي بيحكم على شغله بنفسه بيقول «خلصت» وهو ما خلّصش. أمر بيرجع صفر مابيكدبش.

النموذج

ترانسفورمر decoder-only. التوكنيزر والأوزان كلها متدرَّبة من الصفر — مفيش أي حاجة جاهزة.

التشغيل

البوابة محليًا، والإكستنشن في VS Code.

# البوابة — بتوصل مئات المزوّدين من نقطة واحدة
npm i -g omniroute
OMNIROUTE_SERVER_HOST=127.0.0.1 omniroute serve

# الإكستنشن
git clone https://github.com/AhmedElashry20/elashry-ai.git
cp -R elashry-ai/extension-v0.5.2 \
   ~/.vscode/extensions/ahmedelashry.elashry-ai-0.5.2
OMNIROUTE_SERVER_HOST=127.0.0.1 مش اختياري — السيرفر افتراضيًا بيسمع على كل الشبكة من غير مفتاح.

حاجات اتعلمتها من المشروع

  • خيوط أقل أسرع — على معالج بيتخنق حراريًا، 4 خيوط طلعت أسرع من 8.
  • الحفظ لازم يبقى دوري — الحفظ عند أحسن نتيجة بس ضيّع 9 أيام تدريب.
  • التكبير مش بيضيّع التدريب — بإسقاطات مصفّرة، الطبقة الجديدة بتبقى ممر والـ loss مابيتغيرش.
  • الحارس ممكن يبقى هو المشكلة — حد زمني ضيّق خلاه يقتل تدريب سليم 7 مرات في يوم.
